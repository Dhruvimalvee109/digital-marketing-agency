# Digital Marketing Agency Website

This is a professional and responsive frontend website designed for a Modern Digital Marketing Agency. It showcases various services like SEO, Social Media Marketing, Content Creation, and PPC campaigns.

## 🚀 Features
- **Modern UI/UX:** Clean and fully responsive design for all devices (Mobile, Tablet, Desktop).
- **Interactive Pages:** Includes Home, Blog, Blog Details, Contact, and Project Details pages.
- **Optimized Performance:** Fast-loading frontend with clean HTML, CSS, and JS structure.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (JS)
- Custom Fonts & Responsive Layouts

## 📂 Project Structure
- `/css` - Styling sheets
- `/fonts` - Custom typography
- `/images` - Project assets and visuals
- `/js` - Interactive elements and functionalities
- `index.html` - Home page of the website
